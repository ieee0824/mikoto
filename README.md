# mikoto

Go の関数の長さと、明示的に指定した関数の副作用を検査する解析ツールです。

## 使い方

Go 1.24 以降が必要です。

```sh
go install github.com/ieee0824/mikoto/cmd/mikoto@latest
mikoto -max-lines=80 ./...
```

ソースから実行する場合:

```sh
go run ./cmd/mikoto -max-lines=80 ./...
```

`//mikoto:pure` を関数宣言の直前に付けると、引数・戻り値・レシーバーの値型制限、パッケージ変数の参照、参照先への代入、ポインタの間接参照、チャネル操作、クロージャ、goroutine、`defer`、非決定的な `range`、未指定の関数呼び出しを検出します。値型として基本型と、値型だけで構成される配列・構造体を許可します。呼び出せるのは同一パッケージ内の指定済み関数、型変換、および一部の副作用のない組み込み関数です。`-max-lines=0` で行数検査を無効化できます。

```go
//mikoto:pure
func Double(n int) int { return n * 2 }
```

これは保守的なルールであり、参照透過性の数学的な証明ではありません。浮動小数点や実行環境に依存する挙動、言語ランタイムの特殊な動作まで保証するものではありません。テストも併用してください。
